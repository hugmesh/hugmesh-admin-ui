Games app store

Run dockerized FOSS game servers offered to your domain. Create an instance from an offered server, then start, pause or stop it. Catalog curation + offers are managed by a superadmin.

Create an instance

Pick a server offered to your domain and give the instance a DNS-label name. A superadmin must have offered the server, your admin must have enabled it, and the per-server quota must have headroom — otherwise the request is refused. You can start, pause and stop instances. Creating new instances needs the games app-store admin role.
