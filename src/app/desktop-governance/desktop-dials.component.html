SSH dial management

Each device's BFF→device SSH dial must be active before the in-UI terminal or one-click remote install can go live on it. The BFF authenticates as the dial user with a Vault-mounted dial key (never shown). Ships dark: while app.device-terminal.dial.enabled is off the verifying test-connect is held; this tab is superadmin-only and every action is re-enforced server-side. Activate and revoke each require a fresh single-use step-up token (minted automatically).
