Image generation

Build a device image for a user — a full primary node, a mesh-extension, or a laptop / Chromebook client. Trigger a build, watch live progress, then download the built image and, when the build allowed it, the (non-secret) SSH-keys bundle.

The image generator is not wired to run real cluster builds here — a triggered build is recorded but no image is produced until the generator is enabled.
