Image generation

Build device images for a mesh of users — full primary nodes, mesh extensions, and laptop / Chromebook clients — in one worklist batch. Watch live progress per build, then download each built image and, when the build allowed it, the (non-secret) SSH-keys bundle.

The image generator is not wired to run real cluster builds here — a triggered build is recorded but no image is produced until the generator is enabled.
