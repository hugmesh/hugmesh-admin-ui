Managed backing services

Run each mesh backing service in-mesh (self-hosted, the default) or point it at a managed cloud equivalent (AWS / Azure). Self-hosted is the byte-identical default — no change until you record a managed mode. References only — never credentials; managed creds route to ESO/Vault. Recording a mode is INTENT: the generator (at image build) and the reconciler converge it.
